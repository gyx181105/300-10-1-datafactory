# 启动说明

项目根目录：`d:\code\300-10-1-datafactory`

目录约定：

| 目录 | 用途 |
|---|---|
| `web/` | 前端可视化看板 |
| `server/` | Python 数据流水线与配置 |
| `原始数据/` | 原始基线 CSV / Excel |
| `dataset/`、`output/`、`warehouse/` | 流水线产出 |

建议所有 Python 命令前加上：

```bat
set PYTHONNOUSERSITE=1
```

Python 命令请在**项目根目录**执行（保证 `server\config` 与数据路径正确）。

---

## 1. DuckDB 数据仓库（给大模型查数）

```bat
cd /d d:\code\300-10-1-datafactory
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r server\requirements.txt duckdb
.venv\Scripts\python.exe server\build_duckdb_warehouse.py
```

- 库文件：`warehouse/hcc_llm.duckdb`
- 模型用表结构提示：`warehouse/llm_sql_schema_prompt.txt`
- 试查：`.venv\Scripts\python.exe server\query_duckdb_demo.py`

详见：`DuckDB数据仓库说明.md`

## 2. 启动可视化看板（日常查看）

```bat
cd /d d:\code\300-10-1-datafactory\web
npm install
npm run dev
```

浏览器打开终端里提示的地址（常见为 `http://127.0.0.1:5173` 或 `5174`）。

| 侧栏 | 内容 |
|---|---|
| **LLM Dataset** | 大模型微调语料（主路径） |
| Tabular A | 表格模型对照结果 |
| Overview / Cohort 等 | 清洗与队列概览 |

> 若端口被占用，Vite 会自动换端口，以终端打印为准。

### 仅预览已构建页面

```bat
cd /d d:\code\300-10-1-datafactory\web
npm run build
npm run preview
```

## 3. 生成 / 更新 LLM 训练数据

首次或数据变更后执行：

```bat
cd /d d:\code\300-10-1-datafactory
set PYTHONNOUSERSITE=1

python server\build_training_dataset.py
python server\build_task_a.py
python server\build_llm_dataset_a.py
```

| 步骤 | 作用 |
|---|---|
| `server\build_training_dataset.py` | 清洗去重 + 文本旁路 |
| `server\build_task_a.py` | 患者划分与标签（给 LLM 对齐 split） |
| `server\build_llm_dataset_a.py` | 生成 JSONL 微调数据 |

**产出目录**：`dataset/task_a_llm/`  
- 训练用：`train.alpaca.jsonl`（或 `train.messages.jsonl`）  
- 验证/测试：`val.*.jsonl`、`test.*.jsonl`  
- 摘要：`summary.json`、`sample_preview.json`

更细的规则与验收见：

- `死亡风险分类-特征构建规则.md`
- `死亡风险分类-数据集构建执行步骤.md`

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| `npm` 找不到 | 先安装 [Node.js](https://nodejs.org/)，再执行 `npm install` |
| 缺少 `dedup_raw` / sidecar | 先跑 `server\build_training_dataset.py` |
| 缺少 `features_train.csv` | 先跑 `server\build_task_a.py` |
| 看板数字是旧的 | 更新对应 `web/src/lib/*-data.ts` 后刷新页面 |
| PowerShell 里 `&&` 报错 | 分行执行，或用 `cmd /c "cd /d ... && npm run dev"` |
