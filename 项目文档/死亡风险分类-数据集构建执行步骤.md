# 死亡风险分类 · LLM 数据集构建执行步骤

目标：生成可供大语言模型 SFT / LoRA 微调的 JSONL（病历原文 → 死亡风险 0/1）。

规则全文：`死亡风险分类-特征构建规则.md`

---

## 前置条件

```bat
set PYTHONNOUSERSITE=1
cd /d d:\code\300-10-1-datafactory

python server\build_training_dataset.py
python server\build_task_a.py
```

说明：`server\build_task_a.py` 这里**只用来**得到患者级 `train/val/test` 划分和 `label_death`；真正给 LLM 的输入是病历原文，不是 `X_train.csv`。

---

## 生成 LLM 训练数据（主步骤）

```bat
set PYTHONNOUSERSITE=1
cd /d d:\code\300-10-1-datafactory
python server\build_llm_dataset_a.py
```

---

## 结果在哪里看

目录：`dataset/task_a_llm/`

| 文件 | 用途 |
|---|---|
| `train.alpaca.jsonl` | 训练集（instruction / input / output） |
| `val.alpaca.jsonl` | 验证集 |
| `test.alpaca.jsonl` | 测试集 |
| `train.messages.jsonl` 等 | Chat 格式（system / user / assistant） |
| `sample_preview.json` | 随便看一条长什么样 |
| `summary.json` | 样本量、正例率、平均文本长度 |

**一条样本 = 一个患者**：`input` 里是拼接后的病历，`output` 是 `0` 或 `1`。

用编辑器打开任意 `*.jsonl`，每行一条 JSON，即为 LLM 训练数据。

### 可视化看板

```bat
cd /d d:\code\300-10-1-datafactory\web
npm run dev
```

浏览器打开后点侧栏 **LLM Dataset**，可看样本量漏斗、划分、input 长度、病历段落覆盖与样例预览。

## 怎么拿去训模型

1. 选底座（如 Qwen2.5）+ LoRA/SFT 框架（LLaMA-Factory、Axolotl、官方脚本等）
2. 数据路径指向 `dataset/task_a_llm/train.alpaca.jsonl`（或 messages 版）
3. 验证用 `val.*.jsonl`，最终报告用 `test.*.jsonl`
4. 生成结果解析为 0/1 后与 `label_death` 对比

---

## 和旧表格文件的区别

| 路径 | 是什么 |
|---|---|
| `dataset/task_a_llm/*.jsonl` | **LLM 主数据集（请用这个）** |
| `dataset/task_a/X_*.csv` | 旧表格模型特征，不是 LLM 语料 |
| `output/text_fields_sidecar.csv` | 病历原文旁路；构建脚本会读它来拼 input |

---

## 常见问题

| 问题 | 处理 |
|---|---|
| 缺少 sidecar / dedup | 先跑 `server\build_training_dataset.py` |
| 缺少 features_*.csv | 先跑 `server\build_task_a.py` |
| 看板数字未更新 | 同步 `web/src/lib/task-a-llm-data.ts` 后刷新 |
