# 目录结构

配合 `1-系统功能说明.md` 阅读。路径均相对仓库根目录。

---

## 1. 总览

```text
300-10-1-datafactory/
├── web/                      # 前端看板（Vite + React + Tailwind）
├── server/                   # Python 流水线与配置
├── 原始数据/                  # 医院导出的基线 CSV/Excel（不入库）
├── output/                   # 清洗中间结果（不入库）
├── dataset/                  # Task A 表格集 / LLM JSONL（不入库）
├── warehouse/                # DuckDB 库与 schema 提示（*.duckdb 不入库）
├── docs/                     # 标签等短规范（入库）
├── 项目文档/                  # 中文说明（入库）
├── .venv/                    # 本地 Python 虚拟环境（不入库）
├── .gitignore
└── README.md
```

`server/config` 里 `ROOT` 指向**仓库根目录**（不是 `server/`），因此数据目录始终在根下：`原始数据/`、`output/`、`dataset/`、`warehouse/`。

---

## 2. web/（前端）

```text
web/
├── src/
│   ├── App.tsx               # 页面与侧栏各视图
│   ├── main.tsx
│   ├── index.css
│   ├── components/           # UI 与图表辅助
│   │   ├── ui/
│   │   ├── chart-labels.tsx
│   │   └── svg-patterns.tsx
│   ├── lib/                  # ★ 看板用汇总数据（TS 常量，非实时读盘）
│   │   ├── qc-data.ts
│   │   ├── task-a-data.ts
│   │   ├── task-a-llm-data.ts
│   │   ├── palette.ts
│   │   └── utils.ts
│   └── assets/
├── public/
├── package.json
├── vite.config.ts            # 开发端口等在此配置
└── tsconfig*.json
```

| 路径 | 职责 |
|---|---|
| `src/App.tsx` | 看板主界面 |
| `src/lib/*-data.ts` | 展示用汇总数字；流水线变了要手动同步 |
| `vite.config.ts` | `server.port` / `preview.port` |

---

## 3. server/（流水线）

```text
server/
├── config/
│   ├── __init__.py
│   ├── task_a.py             # Task A 路径、泄漏列、关键词等
│   ├── task_a_llm.py         # LLM 语料路径与拼装约定
│   └── duckdb_warehouse.py   # DuckDB 路径与表说明
├── build_training_dataset.py # 原始数据 → output/
├── extract_text_features_a.py
├── build_task_a.py           # → dataset/task_a/
├── build_llm_dataset_a.py    # → dataset/task_a_llm/
├── train_baseline_a.py
├── build_duckdb_warehouse.py # → warehouse/
├── query_duckdb_demo.py
└── requirements.txt
```

脚本请在**项目根**执行，例如：`python server\build_task_a.py`。

---

## 4. 数据与产出目录

| 目录 | 内容 | Git |
|---|---|---|
| `原始数据/` | 基线 CSV / Excel 源文件 | 不入库 |
| `output/` | `dedup_raw.csv`、`text_fields_sidecar.csv`、划分表、QC 图等 | 不入库 |
| `dataset/task_a/` | `features_*.csv`、`patients.csv`、基线指标等 | 不入库 |
| `dataset/task_a_llm/` | `*.alpaca.jsonl`、`*.messages.jsonl`、`summary.json` | 不入库 |
| `warehouse/` | `hcc_llm.duckdb`（不入库）；可入库的有 schema 提示等小文件 | 部分 |
| `docs/` | 如 `label_spec_a.md` | 入库 |
| `项目文档/` | 中文说明（含本文） | 入库 |
